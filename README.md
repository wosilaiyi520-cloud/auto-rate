# 自动倍速

网页里的 HTML5 视频默认 **1.5x**。按 `+` / `-`（或 `=` / `_`）以 0.25 步进调节，范围 0.5x–3.0x。直播（无限时长）自动跳过。匹配规则：`@match *://*/*`（含所有 iframe）。

## 安装

1. 安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 用 Tampermonkey 打开下面的 raw 地址并安装：

https://raw.githubusercontent.com/wosilaiyi520-cloud/auto-rate/main/auto-rate.user.js

## English

Sets page videos to **1.5x** by default. `+` / `-` change speed in 0.25 steps (0.5x–3.0x). Live streams are skipped. `@match *://*/*`. Install with Tampermonkey from the raw GitHub URL above.
